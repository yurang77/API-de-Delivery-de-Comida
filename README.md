Esta API foi feita para gerir um sistema de delivery de comidas, típico das nossas praças, mercados e cantinas. Ela permite criar pedidos, registar restaurantes, gerir o cardápio e acompanhar o estado das entregas tudo fresquinho, tal como uma matapa acabada de fazer.

Ideal para quem quer montar um serviço de entregas ao estilo Moçambique: rápido, desenrascado e com aquele toque local. A API foi construída com FastAPI, que é bué da rápido e tem documentação automática.
